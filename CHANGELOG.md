# Changelog

## v1.0.0 — Portfolio release preparation

Prepared locally; no Git tag, remote push or published release has been created.

- Per-user chat/upload token buckets, request-correlated safe error responses, strict upload names and HTTP headers.
- Bounded list queries and an application owner/id index migration.
- On-demand Element Plus components/styles and existing lazy routes.
- Explicit LOCAL TEST MODE banner; production no longer imports demo data automatically.
- Public repository check, security/deployment/architecture/demo guides and release hygiene.
